# Данюша: Beauty City — Android TV

Играбельный прототип 2D-платформера для Android TV.

Управление:
- ← / → — движение
- OK / Enter / A — прыжок
- Back — пауза

В уровне:
- Данюша — брюнетка, главная героиня
- кисти для макияжа вместо монет
- beauty-враги и пропасти
- три жизни и контрольные точки
- финиш — косметичка

APK автоматически собирается GitHub Actions.
