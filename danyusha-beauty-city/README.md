# Данюша — Beauty City v0.4

Android TV 6+; целевое устройство — Mi Box 3 / Android TV 9.

## Что изменилось
- Прорисованная брюнетка по первоначальному концепту: розовая куртка, тёмные брюки с полосами, пояс с кистями.
- Спрайты ожидания, бега и прыжка; отражение при движении влево.
- Детализированный розово-золотой город с параллаксом.
- Рисованные кисти, противники-помады, косметичка-финиш и видимые контрольные точки.
- Небольшой буфер прыжка, запас времени после схода с края, защита после возрождения.

## Управление
Стрелки влево/вправо — движение. OK / Enter / A / вверх / пробел — прыжок.
Назад во время игры — пауза. OK — продолжить или начать заново.

## Сборка
JDK 17, Android SDK 35, Gradle 8.9. Команда: gradle assembleDebug.
CI: .github/workflows/build-danyusha-apk.yml в репозитории.

## Проверка
Android instrumentation выполняет загрузку графики, рендер экрана, движение, подбор кистей,
прыжок, паузу, падение/контрольную точку, финиш, перезапуск и завершение игры.
Реальная плавность на Mi Box 3 требует проверки на устройстве.

## Графика
Сгенерирована встроенным инструментом по первоначальному концепту пользователя.
Промпты: согласованный образ брюнетки в розовой куртке / восемь поз для платформера;
розово-золотой город с фасадами бутиков; кисть, помада-противник, косметичка и контрольная точка.
Ресурсы находятся в app/src/main/assets и загружаются офлайн.
